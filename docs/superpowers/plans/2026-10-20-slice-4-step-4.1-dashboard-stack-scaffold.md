# Slice 4 Step 4.1 — DashboardStack Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the dashboard backend's skeleton in AWS — a FastAPI app on a second zip-packaged Lambda behind an API Gateway HTTP API, serving only `GET /api/health` — plus the SPEC amendments the serverless dashboard design requires, so Steps 4.2–4.4 add endpoints and auth onto a deployed, cdk-nag-clean stack.

**Architecture:** `infrastructure/lambda_assets.py` learns to build a layer from `[project].dependencies` **plus** named `[project.optional-dependencies]` extras; a new `dashboard` extra adds `fastapi` + `mangum`. `src/dashboard/api/app.py` exposes a FastAPI app factory and a module-level Mangum `handler`. A new `DashboardStack` (declared **last** in `infrastructure/app.py`, depending only on `DataStack`) owns the API Lambda, its own dependency layer, two log groups, an HTTP API with a single unauthenticated `GET /api/health` route and an access-logged `$default` stage. No SPA, no Cognito, no DB queries yet.

**Tech Stack:** Python 3.11, FastAPI, Mangum, AWS CDK (Python) `aws_apigatewayv2` + `aws_apigatewayv2_integrations` from the pinned `aws-cdk-lib==2.259.0`, cdk-nag, pytest (`asyncio_mode=auto`, `filterwarnings=error`), GitHub Actions deploy.

**Spec:** `docs/superpowers/specs/2026-10-18-serverless-dashboard-design.md` — §3.2 (components), §3.3 (dependency layer, settings), §3.4 (25 s Lambda timeout), §3.5 (deploy), §4.4 (anti-goals: stack last, independent of Compute/Scheduling/Monitoring), §6.1 (`/api/health` contract), §6.2 (module layout), §7 (no cross-stack refs), §8 (Lambda role: no SSM), §10 row **4.1**, §11 (SPEC amendments), §12 (builder calls).
